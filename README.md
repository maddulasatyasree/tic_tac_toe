# Tic.Tac.Toe

Tic tac toe
The Tic-Tac-Toe game was developed using C++. The project allows a human player to play against the computer on a 3×3 grid. The program checks for valid moves, updates the game board after each turn, and determines the winner by checking rows, columns, and diagonals. The computer automatically selects its moves and the game continues until a player wins or the match ends in a draw.
Features:
Human vs Computer gameplay
Winner detection
Draw detection
User-friendly interface
Input validation
Conclusion:
The project successfully implements a Tic-Tac-Toe game using C++. It demonstrates the use of arrays, functions, conditional statements, loops, and basic game logic. The game provides an interactive way to understand programming concepts and problem-solving techniques.
